The `snaplot` entry has no framework code. Everything the React and Solid components do goes
through the same handle that `createChart` returns.

## Lifecycle

`createChart(element, options)` mounts a chart in an element and returns its handle. The chart
fills the element and follows its size, so give the element a height in CSS or pass `height`.

```ts
import { createChart } from 'snaplot';

const chart = createChart(document.getElementById('temps')!, {
  data: rows,
  x: 'date',
  series: [{ y: 'high', label: 'High' }],
  ariaLabel: 'Daily high in Central Park',
});
// later, when the element goes away:
chart.destroy();
```

`destroy()` removes the canvases and listeners and leaves the chart's group.

## update or setOptions

- `chart.update(patch)` merges a patch: `chart.update({ axes: { y: { type: 'log' } } })`.
- `chart.setOptions(options)` replaces every option and applies what differs from the last set.
- `chart.appendData(rows)` adds rows without reading the existing ones again.

## Events and on options

Listen with `chart.on('event', listener)`, which returns the function that removes the listener,
or pass the matching `on…` option:

| Event | Option | Value |
| --- | --- | --- |
| `cursor:change` | `onCursorChange` | The cursor: its x and the points under it. |
| `viewport:change` | `onViewportChange` | `{ x: [from, to] }` after a zoom, `{}` after a reset. |
| `selection:change` | `onSelectionChange` | The selected range and its points, or `null`. |
| `hiddenSeries:change` | `onHiddenSeriesChange` | The ids of the hidden series. |
| `highlight:change` | `onHighlightChange` | The highlighted series id, or `null`. |
| `following:change` | `onFollowingChange` | Whether the chart follows a stream. |
| `point:click` | `onPointClick` | The point clicked. |

<Example name="frameworks/vanilla-readout" />

Events fire for what the reader does (a gesture, a legend click) and for `resetViewport()`,
`resumeFollow()` and group sync, once per action. Setting an option never fires its own event.
`chart.subscribe(listener)` calls back at most once per frame after any change to
`chart.getState()`, which holds the viewport, selection, hidden series, highlight, following and
the series list.

## Groups

`createChartGroup()` links charts: pass the same group as each chart's `group` option, and they
share the cursor, the highlighted series, the x range and the plot edges. See
[Linked charts](/snaplot/guides/linked-charts/).

```ts
import { createChart, createChartGroup } from 'snaplot';

const group = createChartGroup();
createChart(lossElement, { ...lossOptions, group });
createChart(accuracyElement, { ...accuracyOptions, group });
```

## Legend table

`createLegendTable(element, { chart, columns, fallback })` renders a table of each series' value
at the cursor, or at the latest data when there is no cursor (`fallback: 'latest'`). Columns are
`'swatch'`, `'name'`, `'value'`, or `{ header, value(point, series), align }`.

## Cleanup

Destroy what you created, in reverse order: the legend table's `destroy()`, then the chart's.
Remove `on` listeners by calling the function `on` returned, or leave them: `destroy()` drops them.
A group needs no cleanup.
