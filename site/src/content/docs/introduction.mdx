snaplot draws charts on canvas for data that keeps arriving: metrics, logs, sensor readings and
training runs. You describe a chart with one options object, and the same object works in plain
JavaScript, in React and in Solid.

## What snaplot is for

- **Time series and streams.** Append rows or typed columns as they arrive, keep a bounded number
  of points, and follow the latest data in a window of fixed width.
- **Interactive reading.** A tooltip and crosshair, zoom and pan with mouse, touch and keyboard,
  selections, linked charts that share a cursor and an x range, and a legend table that follows
  the cursor.
- **The usual marks.** Line, area, band, bar, histogram and scatter (with colour, size and a
  density mode), with reference lines and regions.
- **One API in three runtimes.** `createChart` in vanilla JS, and a `<Chart>` component with the
  same options in React and Solid. Neither framework is loaded unless you import its entry.

## What it is not for

These are not supported, and the options do not exist:

- stacked marks and horizontal bars;
- animated transitions;
- OHLC and candlestick charts, and X axes that skip gaps in time;
- aggregation of your data beyond `histogram()`;
- a plugin system for new scales.

## Install

<Install />

The package has no dependencies. React (18.3 or 19) and Solid (1.9) are optional peers: install
the one you use.

## Entry points

| Import from | For | Main exports |
| --- | --- | --- |
| `snaplot` | Vanilla JS, and any framework through an element | `createChart`, `createChartGroup`, `createLegendTable`, `histogram` |
| `snaplot/react` | React 18.3 and 19 | `Chart`, `LegendTable`, `useChartState`, `useCursor` |
| `snaplot/solid` | Solid 1.9 | `Chart`, `LegendTable`, `createChartState`, `createCursor` |

The React and Solid entries also export `createChartGroup`, `histogram` and every type, so a
component file needs one import. The package is ES modules only. Without a bundler, import it
from a CDN in a `<script type="module">` (see [Vanilla JS](/snaplot/frameworks/vanilla/#without-a-bundler)).

## Browser support

Chrome and Edge 111 or later, Firefox 115 or later, and Safari and iOS Safari 16.4 or later. The
build targets ES2022 and ships no polyfills.
