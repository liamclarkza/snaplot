## Options every type takes

Every series takes `label`, `color`, `opacity`, `xAxis` and `yAxis`. The table lists what else
each type reads.

| `type` | Reads | Notes |
| --- | --- | --- |
| [`'line'`](/snaplot/chart-types/line/) (default) | `y` | `interpolation`, `dash`, `spanGaps`, `lineWidth`. |
| [`'area'`](/snaplot/chart-types/area/) | `y` | A line filled to zero. `fill` sets the fill; `fill: null` draws the outline only. |
| [`'band'`](/snaplot/chart-types/band/) | `y`, `lower`, `upper` | A range with a centre line at `y`. |
| [`'bar'`](/snaplot/chart-types/bar/) | `y` | One bar per x value; several bar series share each slot. |
| [`'scatter'`](/snaplot/chart-types/scatter/) | `y` | Points; `colorBy`, `sizeBy`, `tooltipFields`, `renderMode`. |
| [`'histogram'`](/snaplot/chart-types/histogram/) | bins | `data` from [`histogram()`](/snaplot/reference/api/snaplot/functions/histogram/). |

## Mixing types

Each series picks its own type, so one chart can hold bars and a line, or a band behind a line.
They share the X axis, and each can take its own Y axis with `yAxis`.
