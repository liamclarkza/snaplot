## Following the page

Without a `theme`, the chart takes its colours from the page it sits on. It finds the first opaque
background behind it, picks light or dark roles from it, and draws on a transparent plot, so a
card, a dark section or a print preview shows through. When the page's theme changes (a class or
`data-theme` attribute on `<html>`, or the system colour scheme) the chart follows.

## Light and dark

`theme: 'light'` or `'dark'` pins the roles whatever the page. Each mode has a colour-blind-safe
categorical palette, a sequential ramp, a diverging ramp and text at 4.5:1 contrast or more on
its surface.

## Tokens

An object of tokens overrides single roles and leaves the rest to the page:

| Token | Role |
| --- | --- |
| `surface` | The colour behind the chart, for contrast; painted only when you set it |
| `text`, `muted` | Strong text; axis labels, legend text, gridlines and the frame |
| `accent` | The crosshair and the focus ring |
| `categorical` | Series colours, in order |
| `sequential`, `diverging` | Ramps for continuous colour and density |
| `fontFamily`, `fontSize` | Chart text |
| `mode` | `'light'` or `'dark'` roles |

Any CSS colour works in a token or a series `color`: names, `#hex`, `rgb()`, `hsl()`, `oklch()`
and `var(--your-token)`.

## CSS variables

Variables on the chart's container, or any ancestor, set roles without code:

| Variable | Role |
| --- | --- |
| `--chart-bg` | The surface (painted) |
| `--chart-text` | Text, and axis labels unless they have their own |
| `--chart-axis-label`, `--chart-tick` | Axis labels and tick marks |
| `--chart-grid`, `--chart-axis`, `--chart-border` | Gridlines, axis lines, the frame |
| `--chart-crosshair` | The crosshair |
| `--chart-tooltip-bg`, `--chart-tooltip-text`, `--chart-tooltip-border` | The tooltip |

Tokens win over variables, and variables over the page.
