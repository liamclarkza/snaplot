## Reference lines and regions

`referenceLines` draws a line at a value of one axis; `referenceRegions` shades the span between
two values. Values are written the way the axis reads them: numbers, `Date`s, ISO 8601 strings or
category labels. A region on a category axis covers its categories' whole slots, and an open end
(`-Infinity` or `Infinity`) runs to the edge of the plot.

On a value axis, lines and regions stay in view: the automatic range takes in a target above the
data the way it takes in the data. A line on the X axis does not widen it, so an old marker beside
a streaming window does not hold the window open, and an axis `min` or `max` still wins.

<Example name="annotations-guide/lines-regions" />

Lines draw over the data and regions under it. Labels never overlap one another: a region's label
sits centred over it on the top row, a label for a horizontal line sits above its line at the
right edge, a label for a vertical line takes the first free row at the top, and each sits on a
halo of the page colour so it reads over the data.

## The plugin contract

A plugin is an object with an `id` and up to three draw hooks, each called with the canvas
context, the chart and the plot rectangle:

| Hook | Draws |
| --- | --- |
| `drawBelow` | under the data, after the grid and the reference regions |
| `drawAbove` | over the data, after the reference lines |
| `drawOverlay` | on the overlay, above the crosshair |

`chart.scale(key)` maps values to pixels (`toPixel`, `fromPixel`), with the axis range, its type
and its categories. `install(chart)` runs once when the plugin is added and may return a cleanup
function. Plugins are matched by `id`, so passing a new object with the same id on every render
changes nothing; two plugins with one id throw. A plugin that throws is disabled, with one
warning, and the chart keeps drawing.

<Example name="annotations-guide/plugin" />

Call `chart.redraw('overlay')`, `'data'` or `'all'` when what a plugin draws changes outside
the chart's options.
