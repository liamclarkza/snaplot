## Axis types

Linear, log, time and category axes.

## Titles

Name an axis with `title`.

## Bounds

Set `min` and `max`, or turn off rounding with `nice: false`.

## Explicit ticks

Choose the tick values with `ticks`.

## Formatting values

`format` takes a function, Intl options, or a prefix and suffix.

## Dual axes

Put a second value axis on the right.

## Locale

`locale` sets the language for numbers and dates.

## Time zones

`timeZone` shows times in local time or UTC.

## Tick and value precision

Ticks round to the step; tooltips show the value.
