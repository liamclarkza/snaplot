## Groups

Create a group with `createChartGroup()` and pass it to each chart.

## What a group shares

The cursor, the x viewport and the highlighted series.

## Sharing the y range

`yRange: true` gives every chart in the group the same y range.

## Aligning plots

`alignPlots` lines up the plot edges.

## Leaving a group

Remove a chart with `update({ group: undefined })` or `destroy()`.

## Shared options

Spread one options object into every chart in a group.
