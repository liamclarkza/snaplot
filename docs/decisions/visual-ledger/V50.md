# V50: the theme follows the page, and the plot is transparent

- **Commit:** `fix(theme)!: surface-first theme resolution and a transparent plot`
- **Milestone:** M11
- **Fixtures:** `axes/*`, `marks/*`, `layout/*`, `overlay/*`, `legend/*`, `theme/*` (every fixture: the plot surface)
- **Before → after:**
  - Before: light or dark came from the OS (`prefers-color-scheme`), and the plot painted an opaque `#fafbfc` (light) or `#14161f` (dark) panel with a seam against the card; a cream page under a dark OS got a black chart.
  - After: light or dark comes from the page behind the chart (an explicit `surface` token or `--chart-bg`, else the first opaque ancestor background, else the page's text colour, else white), and nothing is painted unless a `surface` is given. `theme: 'light' | 'dark'` picks the roles only.
